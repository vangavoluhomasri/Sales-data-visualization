# 📊 Sales Data Visualization Project

## 📌 Project Overview

This project focuses on analyzing and visualizing sales data using Python.

The project transforms sales data into meaningful visualizations to understand
revenue trends, category performance, marketing impact, regional performance,
and profit margins.

## 🎯 Objectives

- Analyze sales and revenue data
- Understand monthly revenue trends
- Compare revenue across product categories
- Analyze the relationship between marketing spend and revenue
- Study correlations between important business metrics
- Compare regional and category performance
- Analyze profit margins across regions

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Git
- GitHub
